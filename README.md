# Список дел для слаеров (To-Do for slayers)

Десктопное приложение для планирования прохождений уровней Geometry Dash по данным
[Global Demonlist](https://demonlist.org). Работает на открытом API, логин не нужен.

## Что умеет

- Список уровней в строку: место, превью, название, статус и быстрые действия.
- Порядок уровней — по позиции в Global Demonlist. Уровни без позиции стоят сверху,
  более новые выше старых. Строку можно перетащить мышкой: порядок станет ручным.
  Можно и просто ввести номер в поле «Место» — уровень встанет на это место.
  Кнопка «Сортировать по позиции в GDL» возвращает исходный порядок.
- Фильтр по статусам — галочки у каждого статуса, работают одновременно; кнопка
  «Сбросить фильтры» показывает все уровни.
- Статусы: Пройден, В процессе, Планируется, Заморожен, Мечта, Мёртв. Цвет каждого
  статуса настраивается, рамка строки, полоса прогресса и фильтры используют его.
- Ролик прохождения от самого слаера (из профиля Global Demonlist) показывается превью;
  клик открывает видео. Вместо превью можно поставить свою картинку с компьютера
  или вставить из буфера обмена; у своей картинки есть кнопка удаления.
- Прогресс вводится текстом: `27-100`, `99.96%`, `75`, `100%`.
- «Фановость» — свободный текст: `95`, `топ`, `легенда`. Старое числовое значение
  из файла данных переносится в строку автоматически.
- «Попытки» — счётчик, который пользователь ведёт вручную (до шести цифр); синхронизация
  его не меняет.
- Синхронизация всегда обновляет статусы и прогресс, но не трогает Заморожен,
  Мечта и Мёртв — они считаются личным решением.
- Синхронизация с профилем Global Demonlist по нику, ID или ссылке. По желанию она
  добавляет уровни, которых в профиле нет, но которые есть в самом листе: в профиле
  API поле `uncompleted` пустое, поэтому список Global Demonlist вычитается из профиля,
  а остаток добавляется как «Планируется». Такие уровни не докачиваются по одному.
- Два языка интерфейса: русский и английский.
- Компактный режим: убирает только превью — название, место, прогресс и попытки остаются.
- Удаление уровня, превью и фоновой картинки спрашивает подтверждение.

## Файл данных и папка данных

По умолчанию всё лежит в `%APPDATA%\to-do-for-slayers`:

```
to-do-for-slayers.json   файл уровней и настроек
strings.txt              русские надписи
strings.en.txt           английские надписи
previews/                свои картинки-превью (сюда же попадает вставка из буфера)
backgrounds/             фоновая картинка приложения
fonts/                   свои шрифты
icon.ico                 свой значок окна (необязательно)
location.json            (служебный) запоминает текущую папку данных
```

Кнопка «Переместить данные…» в настройках выбирает другую папку: туда переносятся
файл данных, оба файла надписей, превью и шрифты. Старая папка остаётся на месте как
резервная копия. При повреждении файла рядом создаётся резервная копия
`.broken-<время>`.

## Свои надписи

Рядом с файлом данных лежат `strings.txt` (русский) и `strings.en.txt` (английский).
Каждый файл — список строк вида «надпись - новая надпись»:

```
Пройден - Passed
В процессе - In progress
Название - Name
```

Слева — надпись приложения как она есть в коде, справа — твой текст. Правая часть
пустая, значит надпись остаётся без изменений. Строки с `#` считаются комментариями,
строки удалять не нужно.

Текст в скобках `{…}` — это подставляемые значения (`{n}` — число, `{name}` — имя,
`{percent}` — процент, `{url}` — ссылка). Их менять нельзя, иначе пропадёт значение.

Файл сохраняется обычным Блокнотом. После сохранения приложение подхватывает
изменения само, перезапускать ничего не надо. Если правки не подхватились, нажми
кнопку «Обновить надписи» в настройках. Кнопка «Открыть папку» показывает сам файл
в проводнике.

## Настройки

Кнопка «Настройки» в сайдбаре:

- Язык: русский или английский.
- Масштаб интерфейса: 1, 1.25, 1.5, 1.75 или 2. По умолчанию интерфейс увеличен в 2 раза,
  при смене масштаба окно перестраивается, поэтому вёрстка не сжимается.
- Компактный режим: убирает только превью из строк.
- Шаблон оформления: 10 готовых наборов цветов, рамок и шрифта.
- Цвета: «Цвет фона» красит полосу позади плашек уровней, «Цвет фона объектов» — сами
  плашки, события и карточки, «Цвет панелей», «Цвет кнопок» и «Цвет текста» — остальное.
  Пустое поле берёт цвет из шаблона. Кнопка «Сбросить цвета» спрашивает подтверждение.
- Фоновая картинка на всё приложение, GIF тоже поддерживается.
- Шрифт: один из системных шрифтов Windows или свой файл `.ttf`/`.otf`.
- Цвета всех шести статусов — сброс к значениям по умолчанию.
- Папка данных, файл сохранения, экспорт копии и импорт из файла.
- Папка галереи: картинки из неё показываются во вкладке «Галерея».
- Файл надписей, кнопка «Обновить надписи».

Всё это хранится в файле данных в поле `settings`.

Иконка окна: если положить `icon.ico` в папку данных (`%APPDATA%\to-do-for-slayers`),
приложение подхватит его при следующем запуске или при возврате фокуса в окно.
Без этого файла используется `build/icon.ico` из сборки.

## Разработка

```bash
npm install
npm run dev
```

Проверка типов и сборка:

```bash
npm run typecheck
npm run build
npm start
```

## Где лежат данные

Файл уровней и событий: `%APPDATA%\to-do-for-slayers\to-do-for-slayers.json`.
Файлы надписей: `%APPDATA%\to-do-for-slayers\strings.txt` и `strings.en.txt`.

Если нового файла ещё нет, приложение при первом запуске переносит старые данные из
`%APPDATA%\gd-planner\gd-planner-data.json` или `%APPDATA%\gd-planner\gd-planner.json`.
Старый файл при этом не удаляется.

## Сборка Windows

```bash
npm run dist
npm run dist:portable
```

`dist` собирает установщик NSIS, `dist:portable` — portable-версию. `dist:portable`
короче и не ставит ярлыки. Обе команды кладут файлы в `dist/`.
